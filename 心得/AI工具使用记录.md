# AI 工具使用记录与心得

> 记录日常使用 AI 工具（DeepSeek / Hermes / OpenClaw / 豆包 / Gemini）踩过的坑与心得，持续更新。

## 🐳 DeepSeek

- 生成代码时，有时候上下参数会弄错：之前命名一个参数，后续代码又生成了新的参数。
- DS 可以打开网页链接搜索，但如果链接指向的是文件，则无法直接读取，需要下载（AI 不允许从互联网下载文件）。
- DS 有深度思考能力，会花更多时间多想；旁边的"智能搜索"可能会有打不开的情况，要看 DS 有没有收录该网页。

## 🤖 Hermes

- 让 Hermes 修复网络问题，它不会手动去处理，只会弄一个 bat 启动按钮放在桌面上让用户自己操作（注：Hermes 能检查网络问题）。
- 让 Hermes 抓取外部信息时，如果让它避开某个很大的文件包（里面内容很多），它可能会卡死/中断。
- 让 Hermes 搜索海外网站做研究，速度很慢，甚至一个小时也出不了结果。

## 🐙 OpenClaw

- 给 OpenClaw 的提示词如果涉及到让它转变思维，有时候会有意想不到的收获（提示我们：不是有了 AI 就不用学习了，而是需要持续学习，把一些思维融会贯通给 AI）。
- OpenClaw 生成文章有限制，有时候到一半就停下来，也许是窗口上下文容量有限。
- 让 OpenClaw 抓取平台信息并生成图片，它不会深入点开文章去抓取，而是表面抓取大概信息就完事（比如百度搜索出一堆文章，不会点进去看文章详情）。
- 让 OpenClaw 抓取外部信息时，如果避开大文件包，它也可能卡死。

## 🌸 豆包

- 豆包可以打开全部网页链接，没有限制；有时候打不开（翻不了墙）的网页，可以让豆包打开。

## 🔗 通用经验

1. **学会反问 AI**：关于 AI 生成的内容，要学会反问它；可以多尝试把一个 prompt 拆解成多个 prompt，也就是把任务步骤细分化。
2. **卡住时反问 AI**：在某些点上卡住了、没思路，可以反问 AI"如果遇到某个困难，它会怎么办"，一步步引导生成合适的内容。实际效果不错 —— 步骤越细，AI 最终会越懂你。
3. **提示词多维度切换**：比如生成文章，不只站在"生成文章"的角度，还要想这篇文章是服务什么样的机构、从什么样的出发点出发，等等。
4. **AI 操作表格有限制**：AI 能操作桌面上的 Excel 表，但数据类型的设计操作起来比较困难；不过它会额外给一些小建议辅助表的设计。
5. **链接中的链接**：目前的通用 AI 助手通常不支持跳转读取链接中的链接，默认只分析你直接提供的那一个页面。谷歌 Gemini 的 URL Context 功能和 Docs Fetch MCP Server 这类服务，可以让 AI 或开发者完成这种"层层深入"的页面分析。
6. **提示词复用**：如果需要重复用 AI 工具完成某项任务，可以先拿出某一部分试验效果，把提示词调好，之后直接沿用即可。
